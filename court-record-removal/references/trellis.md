**Route:** the "Request Redaction" link in the bottom-right corner of the docket page itself. Pressing it from the page to be redacted is the only way in; Trellis does not process requests sent by email, per its own redaction instructions (`https://support.trellis.law/how-to-request-a-redaction`). Free, always.

**Eligibility:** the person named on the docket (the form asks whether the records are about you).

**What you need:** every Trellis URL carrying the user's name. Each URL is its own submission with its own written explanation; there is no bulk option.

**Steps (~20-30 minutes per URL):**
1. Open the docket page, scroll to the bottom right, press Request Redaction.
2. Fill the form: name, email, whether the records are about the user, and the explanation. The court-order upload at the bottom is optional on this route; an empty field does not sink the request.
3. The explanation is the only part the user controls and it must substantiate the request. Say who the user is, name the record, and state the concrete harm: an employer running a search, a landlord, someone using the docket to find where the user lives. Keep it to facts a stranger could check, and do not build it around a privacy law.
4. Attach what backs the harm: police report or court order for physical safety; police report or credit-company letter for identity theft; official credentials for judges, public officials, law enforcement. An order sealing the record processes immediately.
5. Submit. The user presses the button themselves.

**What to expect:** no published turnaround. Requests are worked in arrival order and review runs a minimum of 48 hours; support reaches out if it needs more. Approval removes public logged-out access and Trellis asks search engines not to index the page. Google is the slow part: Trellis puts re-ingestion at up to four to six weeks. If the URL is dead and the Google result persists, the next request goes to Google, not back to Trellis.

**Gotchas:**
- A redaction hides an accurate record. If the docket itself is wrong, fix that at the issuing court first, then send Trellis the errata notice; it will not change a public record the court has not changed.
- Redaction reaches trellis.law and nothing else. Count the other sites carrying the same docket before calling anything done.
- Trellis does this as a courtesy and can refuse: it states no legal obligation to redact absent a court order sealing the record. Not deleted, sealed, or expunged; nothing changes at the courthouse.
- Trellis warns about third-party sites selling the free request for a fee. If trellis.law is the only site carrying the case, the user can file it themselves; the cost is the work.
